# Test World

If you want to try out the Transport-Pipes plugin without building a system from scratch, you can download our pre-built Test World!

This world includes several examples of pipe systems already set up, allowing you to see how different pipes (extraction, colored, golden, etc.) interact with each other.

## How to use it

1. **Download the world file**: [transport-pipes.zip](/world/transport-pipes.zip)
2. **Unzip the file**: Extract the downloaded `.zip` file. You should get a folder containing the world data.
3. **Add it to your server**: Copy the extracted folder into your server's main directory (where your other worlds are located, usually alongside `world`, `world_nether`, etc.).
4. **Load the world**: Use a multi-world management plugin (like Multiverse-Core) to import and teleport to the world. For example, if the folder is named `transport-pipes`, you would use `/mv import transport-pipes normal` and then `/mv tp transport-pipes`.
5. **Test the pipes!**: Explore the world and test the existing pipe systems to see how they work.

> [!TIP]
> Make sure the Transport-Pipes plugin is installed and running on your server before testing the world.
