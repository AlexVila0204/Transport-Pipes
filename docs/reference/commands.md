# Commands & Permissions

## Commands

Here is a list of all commands available in the Transport-Pipes plugin.

| Command | Description | Permission |
|---------|-------------|------------|
| `/tpipes tps` | Shows performance stats (ticks per second, amount of pipes/items currently ticking). | `transportpipes.tps` |
| `/tpipes settings` | Opens the player-specific settings interface. Allows players to change their render distance and render system (Vanilla / Modelled). | `transportpipes.settings` |
| `/tpipes creative` | Opens an inventory with access to every pipe without crafting. **Only works in Creative Mode.** | `transportpipes.creative` |

## Permissions

### General Permissions

| Permission | Description | Default |
|------------|-------------|---------|
| `transportpipes.*` | Grants all Transport-Pipes permissions. | — |
| `transportpipes.tps` | Allows using `/tpipes tps`. | OP only |
| `transportpipes.creative` | Allows using `/tpipes creative`. | OP only |
| `transportpipes.settings` | Allows using `/tpipes settings`. | Everyone |

### Crafting Permissions

These permissions control which pipes and tools a player can craft.

| Permission | Description | Default |
|------------|-------------|---------|
| `transportpipes.craft.*` | Allows crafting all pipes and tools. | Everyone |
| `transportpipes.craft.coloredpipe` | Allows crafting Colored Pipes. | Everyone |
| `transportpipes.craft.extractionpipe` | Allows crafting Extraction Pipes. | Everyone |
| `transportpipes.craft.craftingpipe` | Allows crafting Crafting Pipes. | Everyone |
| `transportpipes.craft.goldenpipe` | Allows crafting Golden Pipes. | Everyone |
| `transportpipes.craft.icepipe` | Allows crafting Ice Pipes. | Everyone |
| `transportpipes.craft.ironpipe` | Allows crafting Iron Pipes. | Everyone |
| `transportpipes.craft.voidpipe` | Allows crafting Void Pipes. | Everyone |
| `transportpipes.craft.wrench` | Allows crafting the Wrench. | Everyone |
