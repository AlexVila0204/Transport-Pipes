# Credits & Contributors

Transport-Pipes has a rich history and is kept alive by the passion of the Minecraft community and its dedicated developers. 

Here are the amazing people who made this plugin possible throughout the years:

## The Team Behind Transport-Pipes

* **[RoboTricker](https://www.spigotmc.org/members/robotricker.126658/) - *Original Creator***  
  Originally created the plugin and laid the foundation. You can view the [original repository here](https://github.com/RoboTricker/Transport-Pipes).
  
* **[BlackBeltPanda](https://www.spigotmc.org/members/blackbeltpanda.8320/) - *Maintainer***  
  Picked up the project, expanded it, and continued its development after the original was abandoned.

* **[AlexVila0204](https://github.com/AlexVila0204) - *Current Developer***  
  Forked the project and extensively updated the code to extend support through modern Minecraft versions (1.21.1+).
  
* **[Matthew Hugley](http://otgt.us.eu.org/about-me.html) - *Sponsor***  
  Generously financed the massive effort required to update the plugin logic and provide continuous support for modern versions.
